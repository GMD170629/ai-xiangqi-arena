# 斗兽棋 · 项目标准规则 `classic-v1`

> 斗兽棋存在多种民间规则。本文件不是宣称“唯一官方规则”，而是为本项目首版锁定一套可测试、可复现的标准规则。未来其他规则必须以独立 `rulesVersion` 增加，不得静默修改 `classic-v1`。

## 1. 基础信息

- Game ID：`dou-shou-qi`
- Rules Version：`classic-v1`
- 玩家数：2
- 阵营：`blue` / `red`
- 蓝方先行
- 棋盘：7 列 × 9 行
- 坐标：列 `a-g`，行 `1-9`

蓝方位于 1-3 行，红方位于 7-9 行。

## 2. 胜利条件

满足任一条件立即获胜：

1. 己方任意动物进入对方兽穴。
2. 吃掉对方全部动物。
3. 对方在自己的回合不存在任何合法动作。
4. 对方因 AI 技术失败达到平台设定的失败条件（记为技术性胜利，不与规则胜利混淆）。

## 3. 动物与等级

| 等级 | 动物 | ID |
|---:|---|---|
| 8 | 象 | `elephant` |
| 7 | 狮 | `lion` |
| 6 | 虎 | `tiger` |
| 5 | 豹 | `leopard` |
| 4 | 狼 | `wolf` |
| 3 | 狗 | `dog` |
| 2 | 猫 | `cat` |
| 1 | 鼠 | `rat` |

通常情况下，动物可以吃掉 **等级小于或等于自己** 的敌方动物。

## 4. 普通移动

除狮、虎跳河规则外：

- 每回合只能移动一个己方动物。
- 向上、下、左、右移动一格。
- 不允许斜走。
- 不能移动到己方动物占据的位置。
- 通过移动到敌方动物所在格完成捕获并替换其位置。
- 任何动物都不能进入自己的兽穴。

## 5. 棋盘特殊地形

### 兽穴 Den

- 蓝方兽穴：`d1`
- 红方兽穴：`d9`
- 进入对方兽穴立即获胜。
- 禁止进入己方兽穴。

### 陷阱 Trap

蓝方陷阱：

- `c1`
- `e1`
- `d2`

红方陷阱：

- `c9`
- `e9`
- `d8`

当敌方动物进入我方陷阱时，其 `effectiveRank = 0`，直到离开陷阱。

因此：

- 防守方任意动物都可以捕获陷阱中的敌方动物。
- 己方动物站在己方陷阱中不会被削弱。

### 河流 River

河流格：

```text
b4 c4   e4 f4
b5 c5   e5 f5
b6 c6   e6 f6
```

只有鼠可以正常进入河流。

## 6. 鼠的特殊规则

鼠等级为 1，但存在以下特殊规则：

1. **陆地上的鼠可以吃陆地上的象。**
2. 象不能吃鼠。
3. 鼠可以进入河流。
4. 水中的鼠只能捕获水中的敌方鼠。
5. 陆地鼠不能直接捕获水中的鼠。
6. 水中鼠不能直接捕获陆地动物。
7. 因此水中的鼠不能直接吃陆地上的象。

这组规则刻意消除“跨水陆捕获”的歧义。

## 7. 狮与虎跳河

狮与虎可以从河岸一侧沿水平或垂直方向跳到河流另一侧的第一个陆地格。

条件：

- 路径必须完整跨越连续河流格。
- 任意一个被跨越的河流格中只要存在鼠（不分敌我），跳跃就被阻挡。
- 落点若为空则正常移动。
- 落点若有敌方动物，则只有在普通等级/陷阱规则允许捕获时才能跳过去吃掉。
- 不允许落在己方动物上。

## 8. 初始布局

### 蓝方

```text
a1 tiger      g1 lion
b2 cat        f2 dog
a3 elephant   c3 wolf   e3 leopard   g3 rat
```

### 红方

```text
a7 rat        c7 leopard   e7 wolf   g7 elephant
b8 dog        f8 cat
a9 lion       g9 tiger
```

双方布局旋转 180° 对应，因此象与鼠隔盘相对。

## 9. 重复局面

为避免 AI 陷入无意义循环，`classic-v1` 使用项目规则：

- 同一个“完整局面 + 当前行动方”第三次出现时，判定为 `DRAW_REPETITION`。

这是产品层为 AI 对局加入的明确规则扩展，必须记录在对局元数据中。

## 10. 动作格式

领域动作建议：

```ts
interface DouShouQiAction {
  type: "move"
  from: Square
  to: Square
}
```

AI 协议中的稳定 action ID：

```text
a3-a4
```

显示文本可以由游戏模块本地化，例如：

```text
象 a3 → a4
```

Core 不得解析这些坐标含义。

## 11. 规则测试最低覆盖

必须至少覆盖：

- 八种动物普通移动。
- 等级相同可捕获。
- 高等级吃低等级。
- 低等级不能吃高等级。
- 鼠吃象。
- 象不能吃鼠。
- 水陆边界上的鼠捕获限制。
- 只有鼠可以入水。
- 狮虎横向/纵向跳河。
- 河中有鼠时阻塞跳河。
- 陷阱等级归零与离开后恢复。
- 禁止进入己方兽穴。
- 进入敌方兽穴胜利。
- 消灭全部动物胜利。
- 无合法动作终局。
- 三次重复和棋。
