# 04 · AI 人格系统

## 目标

人格让“同一个模型”呈现不同的搭档感和表达风格，同时保持 AI 自主落子这一核心。

人格不是数值 Buff，也不是游戏引擎参数。

## 人格由什么组成

```ts
interface AIPersonality {
  id: string
  name: string
  tagline: string
  description: string
  prompt: string
  avatar?: string
}
```

## 首版内置人格

### 稳健老将

关键词：克制、经验、风险意识、不轻易冒险。

典型反馈：
> 你的想法可以，但现在直接压上去会留下后手。我先补一手。

### 激进挑战者

关键词：主动、复杂局面、愿意承担风险、喜欢施压。

典型反馈：
> 这就对了。既然他露了空档，我不打算让他舒服地补回来。

### 冷静分析师

关键词：简洁、理性、不废话、解释清晰。

典型反馈：
> 建议已考虑。我选择先改善子力位置，下一回合再决定是否发动攻击。

### 嘴硬天才

关键词：自信、略带吐槽、不轻易认错，但不能侮辱玩家。

典型反馈：
> 我知道你想冲，但这步真不行。先让我把局面收拾干净。

## 自定义人格

用户可以输入：
- 名称
- 一句话设定
- 完整人格描述

游戏将人格内容作为 Prompt 的 Personality Layer 注入。

## 人格的边界

人格可以影响：
- 语言风格。
- 对风险的主观态度。
- 是否更愿意挑战玩家建议。
- 表达情绪与节奏。

人格不能：
- 越过 Core System Rules。
- 让人类直接指定棋步。
- 让游戏代码替 AI 选择棋。
- 获取引擎评价。

## 防止人格污染协议

即使人格要求“永远服从玩家”，Core System Rules 仍应强调：最终棋步必须由 AI 自己判断，玩家不拥有直接落子权。
